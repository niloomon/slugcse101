# CSE 101 Public Materials

Use this folder for materials that should be published with the website.

Recommended workflow:

- Keep editable PowerPoint files in OneDrive, not in this repository.
- Put OneDrive "Anyone with the link can view" PowerPoint links in `index.md`.
- Put stable public exports here when useful:
  - `materials/slides/` for PDF slide exports or other public slide files.
  - `materials/worksheets/` for worksheet PDFs or other public worksheet files.

Avoid putting private logistics, meeting links, grades, rosters, exams, or unpublished assignments in this repository.
